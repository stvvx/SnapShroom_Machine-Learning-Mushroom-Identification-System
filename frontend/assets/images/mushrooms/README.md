# Mushroom Images Folder

Place your mushroom images here with the following names:

1. `oyster-mushroom.jpg` - Oyster Mushroom
2. `enoki-mushroom.jpg` - Enoki Mushroom  
3. `button-mushroom.jpg` - Button Mushroom
4. `shiitake.jpg` - Shiitake
5. `wood-ear.jpg` - Wood Ear Mushroom
6. `death-cap.jpg` - Death Cap (poisonous)
7. `false-morel.jpg` - False Morel (poisonous)
8. `jack-o-lantern.jpg` - Jack O' Lantern (poisonous)
9. `funeral-bell.jpg` - Funeral Bell (poisonous)
10. `red-cage.jpg` - Red Cage (poisonous)

**Image Requirements:**
- Format: JPG or PNG
- Recommended size: 800x600px
- Max file size: 500KB per image
- Clear, high-quality photos showing key identifying features

After adding images, update the imports in `frontend/app/(tabs)/map.tsx`
