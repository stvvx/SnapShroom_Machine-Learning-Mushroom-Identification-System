🔌 API ENDPOINTS

  POST /api/toxicity/predict
  ├─ Input: Image file (multipart)
  ├─ Output: JSON with mushroom predictions
  └─ Example: curl -F "image=@test.jpg" http://localhost:5000/api/toxicity/predict

  POST /api/toxicity/detect-and-classify
  ├─ Input: Base64 image + options
  ├─ Output: Detailed predictions with crops
  └─ Advanced endpoint

  GET /api/toxicity/health
  ├─ Input: None
  ├─ Output: Model status
  └─ Verification endpoint
